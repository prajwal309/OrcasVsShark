# Board research and heritage

Orcas vs Sharks is an original ocean-themed digital adaptation of Bagh-Chal, a traditional asymmetric strategy game of Nepal. We do not claim an exact invention date or equate its rules with other regional games.

Independent sources consulted on 20 September 2026:

- Gutiérrez-Perera, Fernández-Oliveras, and Oliveras (2016), [Play in Scientific and Mathematical Non-Formal Education. Bagh Chal, a Tigers-and-Goats Game](https://www.europeanproceedings.com/article/10.15405/epsbs.2016.05.19), DOI 10.15405/epsbs.2016.05.19. Section 4.1 describes 20 goats, four tigers, a five-by-five intersection grid, and six diagonal lines. It identifies the game as Nepali and discusses its educational use.
- [igGameCenter, Bagh Chal rules](https://iggamecenter.com/en/rules/bagh): independent rules and traditional board reference. External rule variations do not override AGENTS.md; in particular, no repetition restriction has been imported.

The graph was freshly expressed as five horizontal, five vertical, and six diagonal straight node sequences. The full diagonals run a1–e5 and a5–e1; the shorter diagonals run a3–c1, c1–e3, a3–c5, and c5–e3. Every consecutive segment is an edge, and only consecutive collinear triples allow capture. Independent tests enumerate all 625 node pairs and 15,625 triples.

No photograph, decorated board, commercial design, legacy implementation, or source code was traced or copied. The ocean and sand themes change appearance only; both retain identical Bagh-Chal connectivity and rules.
