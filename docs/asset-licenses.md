# Asset and dependency provenance

The Tiger and Goat medallions in `components/board/themed-piece.tsx` and woodland scene in `components/board/forest-background.tsx` are original SVG illustrations drawn for this project without reference images, external assets or traced compositions. Project licensing is pending the owner's decision.

The Cape Cod coastal background in `components/board/cape-cod-background.tsx` is original SVG artwork created for this project, with no external images, traced maps, or fonts. Project licensing is pending the owner's decision. It depicts a stylized coastline rather than a geographic survey.
